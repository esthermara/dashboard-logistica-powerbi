# 📦 Dashboard de Logística — Power BI

## 📌 Sobre o projeto

Projeto de análise de dados desenvolvido em Power BI com o objetivo de acompanhar indicadores de uma operação logística.

Este projeto foi desenvolvido como um **case empresarial fictício**, exclusivamente para fins de estudo e portfólio.

## 🎯 Objetivo

O dashboard tem como objetivo auxiliar no acompanhamento da operação logística, permitindo analisar:

- volume de pedidos;
- entregas realizadas;
- entregas no prazo;
- entregas atrasadas;
- ocorrências;
- desempenho operacional;
- evolução dos indicadores ao longo do tempo.

## 🛠️ Ferramentas utilizadas

- Power BI
- Power Query
- DAX
- Excel

## 📊 Principais indicadores

- Total de pedidos
- Total de entregas
- Entregas no prazo
- Entregas atrasadas
- Percentual de entregas no prazo
- Tempo médio de entrega
- Quantidade de ocorrências
- Desempenho por período
- Desempenho por veículo
- Desempenho por filial

## 🔎 Análises realizadas

O dashboard permite analisar o desempenho logístico através de diferentes dimensões, como:

- período;
- filial;
- veículo;
- situação da entrega;
- ocorrência;
- motivo da ocorrência.

## 🧠 Conhecimentos aplicados

Durante o desenvolvimento foram aplicados conhecimentos de:

- tratamento e transformação de dados;
- Power Query;
- modelagem de dados;
- criação de medidas DAX;
- criação de KPIs;
- análise de indicadores logísticos;
- visualização de dados;
- construção de dashboards;
- storytelling com dados.

## ⚠️ Observação sobre os dados

Este é um projeto fictício desenvolvido exclusivamente para fins educacionais e de portfólio.

Os dados utilizados são simulados e não representam uma empresa, cliente ou operação logística real.

## 👩‍💻 Projeto de portfólio

Projeto desenvolvido para demonstrar conhecimentos em **Análise de Dados, Power BI e Indicadores Logísticos**.
